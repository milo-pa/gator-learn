500

Internal Server Error in Backend Server

The server encountered an unexpected condition that prevented it from fulfilling the request. This typically indicates an issue in the backend logic, configuration, or database connection.

Check your server logs for stack traces or database connection errors. If you’re running locally, ensure your database service is active and that port forwarding or environment variables are correctly configured.

You can test known working endpoints such as /api/listings to confirm whether the backend is responding correctly.
